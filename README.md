# lbu-focp-coffee-shop

Basic Python Programming Example

## Part 1

A small coffee shop has an EPOS system that exports details of each
sale. The format is CSV, and there is one file for each day. Some
sample data is:

    espresso,1,2.50
    latte,3,3.60
    americano,1,2.90
    macchiato,4,2.95
    flatwhite,3,3.65
    latte,2,3.60

The price is stored for each transaction because the unit price can
change because of discounts, club memberships, and the like.

The first output will be the total takings for a day.

## Part 2

The owner would now like to know the total number

average value.

They would also like the output to display the
